# The Aegis’s Oppai · XC2S2 Edition — v0.1.10

- **"Update game" stopped at once with `source:`** on an install that was added as a folder (made by hand, or before the
  launcher noted its dump). The launcher now finds the dump from the install's own game files. Needed for the port's new
  **v0.2.0**.
- During an update the working `xc2_boot.exe` is kept aside and put back if the update stops, so the game still starts.

---

**Español:** «Actualizar juego» fallaba enseguida (`source:`) en instalaciones agregadas como carpeta; ahora encuentra el
volcado solo. Hace falta para la v0.2.0 del port. Durante la actualización se guarda el `xc2_boot.exe` que anda y se
vuelve a poner si algo falla.
